<interfaces>
Доступно через `window.scrubber.settings` (Plan 03):
- `saveApiKey(key: string): Promise<Result>` где `Result = { ok: true } | { ok: false; reason: string }`
- `hasApiKey(): Promise<Result<boolean>>` — `{ ok: true, data: boolean } | { ok: false, reason }`
- `clearApiKey(): Promise<Result>`
- `getSecureBackend(): Promise<Result<SecureBackend>>` где `SecureBackend = 'keychain' | 'dpapi' | 'libsecret' | 'kwallet' | 'basic_text' | 'unavailable'`

Renderer пишется на React 19 + Tailwind v4 (utility classes без конфига). Никаких импортов из `electron`, `node:*` (D-15).
</interfaces>

| renderer → preload → main | Уже покрыто Plan 02/03 (allow-list, типизация, валидация в main). |
