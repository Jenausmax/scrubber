<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → preload | renderer (web context) может только звать функции в exposed `window.scrubber.*`. Не имеет ipcRenderer, fs, path, child_process — sandboxed (D-14). |
| preload → main (ipcRenderer.invoke) | Каналы whitelisted через `Channels.*`. Аргументы передаются как unknown — main валидирует (см. Plan 02 T-01). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01 | Elevation of Privilege | Renderer compromise (XSS, malicious npm dep в renderer) → попытка достучаться до main | mitigate | D-08 + D-14: preload экспонирует ТОЛЬКО 4 типизированные функции settings. Никакого `ipcRenderer`, `fs`, `child_process` в renderer (sandbox + contextIsolation). fail-loud при `process.contextIsolated === false`. |
| T-02 | Information Disclosure | API-ключ в renderer-памяти / DOM | mitigate | D-05: `hasApiKey` возвращает boolean, не ключ. UI Settings (Plan 04) не отображает значение. Renderer не имеет API получить plaintext ключ. |
| T-03 | n/a в этом плане | — | accept | UI-баннер про basic_text — в Plan 04. |
