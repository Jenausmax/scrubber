## Phase Goal

**As a** разработчик scrubber, **I want to** иметь типизированный IPC-контракт `media.*` и build-инфраструктуру (CJS utility entry + asarUnpack), **so that** последующие планы могут немедленно реализовывать сервис извлечения и UI без переделки контракта или сборки.

<objective>
Заложить контракт + build-инфраструктуру вертикального слайса Phase 2:
1) расширить `shared/ipc.ts` namespace `media`, регистрационный slot и preload-bridge;
2) подготовить electron-vite на сборку utility-entrypoint в CJS-формате;

Purpose: контракт-first — устранить сценарий «scavenger hunt», в котором исполнитель угадывает форму payload и каналов.
Output: skeleton-handlers (возвращают `internal`-stub), типы, конфиги — каждый артефакт виден тестами и/или `npm run build`.
</objective>
