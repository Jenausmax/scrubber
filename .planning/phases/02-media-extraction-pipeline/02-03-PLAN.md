<interfaces>
Доступный с Plan 02 контракт `window.scrubber.media`:

```typescript
interface MediaApi {
  pickFile: () => Promise<Result<{ path: string } | null>>
  probe: (path: string) => Promise<Result<MediaProbeResult>>            // { durationSec, sizeBytes, name }
  extractAudio: (path: string) => Promise<Result<MediaExtractResult>>    // { jobId, audioPath }
  cancel: (jobId: string) => Promise<Result>
  onProgress: (cb: (e: MediaProgressEvent) => void) => () => void        // { jobId, percent, etaSec } | unsubscribe
}

type MediaReason = 'invalid_argument' | 'not_mp4' | 'file_not_found'
                 | 'ffmpeg_failed' | 'cancelled' | 'disk_full' | 'internal'
```

Mapping reason → user copy (точный, из UI-SPEC §Copywriting Contract):
- `not_mp4` → `Поддерживается только формат .mp4. Выберите другой файл.`
- `file_not_found` → `Файл не найден. Возможно, он был перемещён или удалён.`
- `ffmpeg_failed` → `Не удалось извлечь аудио. Файл повреждён или неподдерживаемый кодек.`
- `disk_full` → `Недостаточно места на диске для извлечения аудио. Освободите место и попробуйте снова.`
- `internal` → `Внутренняя ошибка. Попробуйте перезапустить приложение.`
- `invalid_argument` (multi-drop) → `Можно перетащить только один файл за раз.`

FSM (UI-SPEC §State Map):
```
idle / idle-drag-over → validating → selected → extracting → done | cache-hit | cancelled | error
```
