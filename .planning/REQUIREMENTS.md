# Requirements: scrubber

**Defined:** 2026-05-27
**Core Value:** Превратить mp4-видео в качественный текстовый транскрипт (`.md`) — это обязано работать, даже если всё остальное отвалится.

## v1 Requirements

Требования для первого релиза. Каждое маппится на фазы роадмапа.

### App Shell (Каркас)

- [ ] **SHELL-01**: Пользователь видит окно приложения с базовым UI на Windows, Linux и macOS
- [ ] **SHELL-02**: Приложение хранит API-ключи в безопасном системном хранилище (safeStorage), а не в plaintext
- [ ] **SHELL-03**: Пользователь получает понятное предупреждение, если безопасное хранилище недоступно (Linux без keyring)

### Media (Медиа)

- [ ] **MEDIA-01**: Пользователь может выбрать mp4-файл через диалог выбора файла
- [ ] **MEDIA-02**: Пользователь может перетащить mp4-файл в окно (drag&drop)
- [ ] **MEDIA-03**: Приложение извлекает аудиодорожку из выбранного mp4 через ffmpeg
- [ ] **MEDIA-04**: Извлечение аудио работает в упакованной сборке на всех трёх ОС (бинарник ffmpeg доступен из прода)

### Transcription (Транскрипция)

- [ ] **TRANS-01**: Пользователь может транскрибировать аудио локально через whisper.cpp на своей машине (офлайн)
- [ ] **TRANS-02**: Пользователь может выбрать модель Whisper и скачать её по запросу (модели не бандлятся)
- [ ] **TRANS-03**: Транскрипция по умолчанию использует русский язык (`language=ru`) с VAD
- [ ] **TRANS-04**: Пользователь видит прогресс транскрипции в реальном времени
- [ ] **TRANS-05**: Пользователь может отменить идущую транскрипцию (Cancel)
- [ ] **TRANS-06**: UI не зависает во время длительной транскрипции
- [ ] **TRANS-07**: Транскрипт сохраняется в `.md`-файл, который пользователь может открыть

### Analysis (Анализ через LLM)

- [ ] **ANLZ-01**: Пользователь может настроить подключение к LLM: URL, API-ключ и модель (OpenAI-совместимый endpoint, включая локальные Ollama/LM Studio)
- [ ] **ANLZ-02**: Пользователь может вести библиотеку именованных системных промптов (создать/просмотреть/изменить/удалить)
- [ ] **ANLZ-03**: Приложение поставляется с 2-3 готовыми русскими системными промптами (например «Суммаризация», «Протокол встречи»)
- [ ] **ANLZ-04**: Пользователь может отправить транскрипт + выбранный системный промпт в LLM и получить ответ
- [ ] **ANLZ-05**: Результат анализа показывается в окне приложения
- [ ] **ANLZ-06**: Результат анализа сохраняется отдельным `.md`-файлом

### Distribution (Дистрибуция)

- [ ] **DIST-01**: Приложение собирается в устанавливаемый артефакт под Windows
- [ ] **DIST-02**: Приложение собирается в устанавливаемый артефакт под Linux
- [ ] **DIST-03**: Приложение собирается под macOS, подписано и нотаризовано (все вложенные бинарники подписаны)

## v2 Requirements

Отложено на будущий релиз. Учтено, но не входит в текущий роадмап.

### Cloud Transcription

- **CLOUD-01**: Пользователь может транскрибировать аудио через облачное API (OpenAI STT) как альтернативу локальному
- **CLOUD-02**: Приложение проверяет лимит размера (25 МБ) и/или длительности перед отправкой в облако, иначе чанкует или явно отклоняет

### Additional LLM Presets

- **PRESET-01**: Пользователь может выбрать готовый пресет Claude (Anthropic Messages API)
- **PRESET-02**: Пользователь может выбрать готовый пресет Gemini (Google)

### Transcription Quality

- **QUAL-01**: Пользователь может выбрать русско-тюненую Whisper-модель для лучшей точности
- **QUAL-02**: Пользователь может задать `initial_prompt`/словарные подсказки для повышения точности
- **QUAL-03**: Пользователь может повторно запустить анализ без повторной транскрипции
- **QUAL-04**: Пользователь может редактировать транскрипт перед анализом

## Out of Scope

Явно исключено. Зафиксировано, чтобы предотвратить расползание скоупа.

| Feature | Reason |
|---------|--------|
| Пакетная обработка / очередь файлов | v1 — один файл за раз; простота важнее |
| Диаризация спикеров | Высокая сложность, не входит в ядро ценности v1 |
| Запись с микрофона (live) | Фокус на готовых mp4-файлах |
| Многоходовой чат с LLM | v1 — single-shot анализ; чат усложняет UX |
| Встроенный видеоплеер | Не нужен для транскрипции |
| Облачное хранилище / синхронизация | Приложение локальное |
| Форматы кроме mp4 | Сужаем v1; расширение возможно позже |
